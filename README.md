# LAB ESCAPE — Jetpack Joyride Arcade

Полноценная пиксельная 2D-аркада в стиле *Jetpack Joyride* на чистом HTML5, CSS3 и JavaScript (Canvas 2D + Web Audio API).

## Файлы проекта
- `index.html` — разметка экранов (старт, пауза, магазин ранцев, рулетка за Жетон удачи, Game Over, HUD).
- `style.css` — адаптивный интерфейс, пиксельные рамки и стили для ПК и смартфонов.
- `sound.js` — ретро-синтезатор звуковых эффектов на Web Audio API (без внешних аудиофайлов).
- `sprites.js` — пиксельная отрисовка лаборатории с параллаксом, бегущих ученых и главного героя.
- `game.js` — физика полета и гильз, препятствия, монеты и комбо, бонусы, миссии, магазин и сохранения в `localStorage`.

## Управление
- **Полет / тяга вверх:** удерживайте **Пробел**, **ЛКМ** или **касание экрана**.
- **Быстрый старт / рестарт / рулетка:** клавиша **Пробел**.
- **Пауза:** **Esc** / **P** или кнопка паузы в правом верхнем углу.
